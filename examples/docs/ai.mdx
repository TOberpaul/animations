<PageHeader title="AI integration">Connect your coding assistant to Motion Development Kit (MDK) through MCP.</PageHeader>

<section id="overview">
  <h2>Build with your AI assistant</h2>
  <p>The public MDK MCP server gives your coding assistant access to the library guide, CSS tokens, TypeScript API and integration examples.</p>
</section>

<section id="setup">
  <h2>Connect the MCP server</h2>
  <p>In Kiro, place <code>motion-library</code> directly under the existing <code>mcpServers</code> key. The example below shows a complete file with one server. In other clients that support remote MCP, use the same URL with the Streamable HTTP transport.</p>
  <pre><code>{JSON.stringify({mcpServers:{'motion-library':{url:'https://emjicqiqcpmkindocsnt.supabase.co/functions/v1/mcp'}}},null,2)}</code></pre>
  <p>The endpoint is public and requires no sign-in, API key or local checkout. Install <code>@tobiasoberpaul/mdk</code> in your project when you use the animation API in your code.</p>
  <p>For a client that only supports stdio, follow the <a href="https://github.com/TOberpaul/animations/blob/main/docs/AI_INTEGRATION.md#local-stdio">local setup</a>.</p>
</section>

Preserve its positioning and keyboard behavior.</blockquote><p>The read-only tools return reference text and example code. Your coding assistant applies changes through its own tools.</p></section>

The reference guide and API are available on the Documentation page.</p></section>
