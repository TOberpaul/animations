# Code playground

Use the HTML editor to try MDK with your own markup. The preview runs the library in the browser.

## Try a transition

1. Add a trigger button and a target panel in the editor.
2. Choose a behavior with `data-motion`, such as `grow`, and link the trigger with `data-motion-trigger`.
3. Use the preview controls to open or close the panel. Drag **Frame** to inspect an intermediate state.
4. Use **Export HTML** to save the example or **Reset** to restore the starter markup.

For installation and controller setup, see {props.documentationLink}.
