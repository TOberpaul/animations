# Motion examples

Explore reversible UI motion in two component libraries. Both use the same MDK controllers and CSS tokens.

## Patterns

- **Grow:** action menus, dialogs, notifications and anchored panels.
- **Extract:** expand from a trigger while retaining the original button.
- **Morph:** transition between an action and a replacement surface, such as a rename input.
- **Slide:** move a drawer or navigate between menu levels.
- **Content:** reveal text, images or grouped page content.

## Providers

{props.providers}

In the interactive examples, open and close a surface repeatedly to try reversal. Motion settings let you adjust duration, overshoot, progressive reveal and reduced motion.
