---
name: resume-work
description: Write a short handoff when moving unfinished work to a fresh Codex chat, or resume from a supplied handoff.
---

For an unfinished package, write a handoff of at most eight lines at a user-supplied path or an unused `HANDOFF.md` path in the workspace. Include goal and acceptance criterion, initial points, checkout and relevant files, verified state, and the next action. Point out uncommitted changes when the next chat needs the same working tree. Link to durable local rules only when useful. Share the handoff path.

Include the existing analytics package ID when available. When resuming, read the supplied handoff, verify the working tree and relevant local rules, and continue the same package with its original estimate.
